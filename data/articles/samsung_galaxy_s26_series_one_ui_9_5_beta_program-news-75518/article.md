# Samsung, Galaxy S26 serisi için bu ülkelerde One UI 9.5 beta programını duyurdu

Samsung'un uygun Galaxy cihazları için stabil One UI 9'u kullanıma sunma süreci hâlâ devam ediyor ancak iki ay önce stabil One UI 9 güncellemesini alan Galaxy S26 serisi için One UI 9.5 beta programını çoktan başlattı.

Ancak One UI 9.5 beta programı tüm bölgelerde açık değildir. Şu anda Almanya, Hindistan, Polonya, Güney Kore, Birleşik Krallık ve ABD'de mevcuttur.

Bu ülkelerden herhangi birinde yaşıyorsanız ve kararlı One UI 9.5 güncellemesini beklemek istemiyorsanız Galaxy S26 serisi akıllı telefonunuzdaki Samsung Members uygulaması aracılığıyla One UI 9.5 beta programına kaydolabilirsiniz. Uygulamadaki One UI 9.5 beta programı başlığına dokunun ve ekrandaki talimatları tamamlayın.

Beta programına kaydolduktan sonra, One UI 9.5 beta güncellemesini kontrol etmek için telefonunuzda Ayarlar > Yazılım güncellemesi menüsüne gidin. Galaxy S26, Galaxy S26+ ve Galaxy S26 Ultra için ilk One UI 9.5 beta güncellemesi, ZKN ile biten bir ürün yazılımı sürümüne sahiptir. Kasım 2026 Android güvenlik yaması ile birlikte gelir ve yaklaşık 3,6 GB'lık bir indirme gerektirir. Gerçek indirme boyutu modele ve bölgeye göre değişebilir.

Samsung, One UI 9.5 kararlı güncellemesinin piyasaya sürülme tarihini henüz açıklamadı. Ancak Galaxy S27 serisi, kararlı One UI 9.5'i çalıştıran ilk seri olabilir.
